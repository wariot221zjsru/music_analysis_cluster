怎么转的

  1. 移调：按「原调主音 → 目标调主音」最近的距离整体移调（拼写、 和弦、谱号都由记谱引擎处理）。移完之后谱子落在目标主音的原调式上。
  2. 调式改写：把落在原调式音级上的音改写到目标调式的同音级—— {% if src.mode == 'major' %} 大调 → 自然小调：降 3 / 6 / 7 级；大调 → 和声小调：降 3 / 6 级 （保留大调的导音，才有和声小调那个增二度）。 {% else %} 小调 → 大调：升 3 / 6 / 7 级（和声小调里已经升过的 7 级原样保留， 到新调里就是大调的导音）。 {% endif %}
