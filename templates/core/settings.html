主旋律线追踪（逐段 · MIR 口径）

这一组只作用于「主旋律线追踪（逐段）」卡片，与上面的交接检测无关： 追踪不受"是否交接"门控，前奏 / 间奏 / 尾奏同样提取。

人声在唱就归人声；人声休止的段落退回最突出的器乐声部。

短于此值的归属碎片并入相邻段，抑制窗间抖动。默认 2。

段内平均 margin（第一名 − 第二名显著性）≥ 该值标为「高」。

低于它标为「低」——两段归属接近，建议人工复核。

主旋律线追踪 · 形态资格层（可选）

形态决定「有没有资格」，显著性决定「谁更强」——形态只做否决， 不参与显著性加分、不改置信度。用来挡住分解和弦、阿尔贝蒂低音、固定音型这类 「周期音型」被误判成主旋律（它们的动机重复度接近满分，单看显著性容易赢过真人声）。 默认关闭：关掉后只看显著性，与以前完全一致。

开启后：段内声部的旋律轮廓形态分达不到下限就失去当主旋律的资格， 由段内形态合格且显著性最高的声部顶上。

形态分（0–1）= 级进比×0.7 + 拱形度×0.15 + 轮廓平滑度×0.15，低于该值即失去资格。 级进比权重最高——分解和弦在轮廓上同样是"平滑大波浪"，只有级进比能识破它。 调高 = 卡得更严；调低 = 更宽容。段内音符太少不足以统计轮廓时一律放行。

主旋律导出（节奏 / 音色）

两张主旋律卡（⑨ 选轨、⑩ 逐段）共用的默认导出方式。 每个作品详情页上还能单独临时改，改完点「应用并重新导出」即可，不必重跑分析。 以前导出是写死的 120 BPM + 默认钢琴，听起来永远只有一种乐器，这里就是用来改掉它的。

拼接类导出（⑨ 交接 / ⑩ 无缝版）小节会与原曲错位，变速标记无意义，自动按单一速度写入。

仅在「导出节奏 = 统一 BPM」时生效，默认 120。

「各段原始音色」用每段自己声部的 MIDI 音色号，多段接力时能听出换乐器。

仅在「导出音色 = 统一音色」时生效，默认 0 · 大钢琴。

分析窗口

显著性 · 织体密度口径

显著性四项里的「织体密度倒数」（越稀疏越像旋律）用哪种算法数音。 默认按发音数：柱式和弦伴奏一个事件顶三个音，只数事件会显得它很稀疏， 显著性会反超真正的旋律（实测有曲子钢琴伴奏 6 个和弦 18 个音，比 8 个音的主题 还被算得更"稀疏"）。按事件数计算的口径保留着——它更接近书写复杂度， 想对比两种口径的效果时把它关掉即可。

勾上 = 和弦内部每个音都计入密度（默认）；不勾 = 一个和弦只算 1 个发声事件， 与早期口径一致。改完请重跑声部识别，主旋律线会自动跟着重算。

主旋律判定 · 力度（听感）

主旋律 = 听感上最像主旋律的那条线，各项指标都是在拟合这种"像"。 力度是其中最直接的一条证据：两条线其它方面差不多时，耳朵会跟着响的那条走。 默认算进去——明显弱于对手的低音不当主旋律（作曲家写它 pp，它就是退让的）， 明显更响的低音可放宽轮廓 / 实质门槛，显著性分不出高下时偏响的那条赢。 谱面没标力度时这项自动失效（既不帮谁也不拦谁）——没标力度不等于力度相同。 想退回纯形态 / 显著性的判据时把它关掉即可。

勾上 = 低音区保护与"显著性打平"两种裁决都把力度算进去（默认）； 不勾 = 完全不读力度，与加这条能力之前的口径一致。 改完请重跑声部识别，主旋律线会自动跟着重算。

主旋律线 · 双音

主旋律本身就可能是一串双音——平行三度 / 六度、加八度、加和声音的主题 都是这么写的，它们依然是主旋律。所以默认保留双音：谱面一个发声事件有几个音， 导出的主旋律线就原样保留几个音（和弦），不会把它压成一条骨瘦如柴的单音线。 关掉才做主音判定：在每个同时响多个音的瞬间里挑出「主旋律在唱的那一个」， 其余按和声填料丢掉。判定用三条证据加权——候选层轮廓（把每个事件按音高排位 拆成几条线，各自打形态分）、和弦成员度（旋律的外音多，填料几乎全是和弦内音）、 相对低音的位置漂移（填料钉在根 / 五 / 三轮换上，平行三度旋律会漂移）； 三条咬得太紧分不出高下时交给 DeepSeek 判定，判断与理由会显示在 作品页主旋律线那张卡的右侧面板里。

勾上 = 导出的是和弦（默认），导出文件名带「保留双音」； 不勾 = 只留主音那一个音，文件名带「单音主音」。 改完请重跑主旋律线追踪，两种口径的产物各存一份，互不覆盖。

DeepSeek 兜底裁定（选轨 · 选音）

本地判据是四条显著性加形态、力度两票，它们都是统计量。总有那么几处 它们互相咬住、分不出高下 —— 这时候"谁更像主旋律"其实已经是一个音乐判断。 勾上（默认）就把这些难判的地方交给 DeepSeek 裁决，并把它的判断与理由 显示出来（作品页主旋律线那张卡里，左侧是本地证据、右侧是模型的说法）。 两类场合会用到它：
① 选轨：几个候选声部咬得太紧，第一名与第二名差距过小；
② 选音：单音模式下，一段双音里几条候选层难分主次。
模型不可用（没装 dsh、超时、返回不可解析、说了个不存在的声部）时一律 静默退回本地最优，不会让整步分析失败 —— 也就是说它只能帮你把难判的 那一处判得更好，永远不会把分析拖垮。

不勾 = 完全靠本地判据，一次网络请求都不发（离线可用，结果与早期版本一致）。 一次分析最多问 24 个窗，超预算的难判窗仍按本地结果。 改完请重跑主旋律线追踪。
